# SC30 - Brand Identity

## Overview

SC30 es la marca personal de Sergio como desarrollador de software.

La marca busca representar:

* Desarrollo de software profesional
* Creatividad aplicada a productos reales
* Modernidad tecnológica
* Aprendizaje continuo
* Construcción de soluciones digitales

SC30 será la identidad principal utilizada en:

* Portfolio
* GitHub
* LinkedIn
* CV
* VerboLab
* Proyectos futuros
* Material de clientes y freelance

## Design Principles

The logo should be:

* Minimalist
* Geometric
* Readable
* Scalable
* Professional

Avoid:

* Gamer aesthetics
* Excessive glow effects
* Complex illustrations
* Generic coding symbols
* Overly futuristic cyberpunk styles

---

## Brand Positioning

SC30 represents a developer capable of taking a project:

From Idea to Product

The focus is not only writing code, but designing, building, deploying and maintaining complete digital solutions.
